# 口琴练习系统

基于简谱的口琴指法可视化练习工具。

## 项目结构

```
.
├── README.md        # 本文件
├── MUSIC.md         # 简谱标记规则 & 口琴谱规则
├── package.json     # npm 启动脚本
├── scripts/
│   └── start-server.mjs # 本地静态服务器
├── index.html       # 口琴练习系统（纯前端）
└── 我的祖国.txt     # 简谱示例文件
```

## 快速开始

使用 npm 启动本地预览服务器：

```bash
npm install
npm start
```

默认地址是 <http://127.0.0.1:2001>。打开页面后，点击「选择文件」加载任意 `.txt` 简谱文件。

如需指定端口：

```bash
npm start -- --port 3000
```

## 功能

- 简谱文件解析（支持 `#` 升音、多八度标记、休止符 `0`）
- 类 LaTeX 简谱显示：上方点表示高八度，下方点表示低八度，`♯` 表示升音
- 12 格 / 20 格两种口琴孔位模式切换
- 表头按 12 格核心区显示 `1` 到 `12`，20 格模式下左右扩展格留空
- 核心区 `4/5`、`8/9` 之间使用加粗竖线分组
- 吹气音符（1,3,5）绿色显示，吸气音符（2,4,6,7）红色显示
- 多栏布局（1-10 栏可调，句块按指定栏数换行排列）
- 歌词展示（`//` 注释内容）
- 句块分隔显示
- 响应式适配
