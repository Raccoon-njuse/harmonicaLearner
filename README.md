# 口琴练习系统

基于简谱的口琴指法可视化练习工具。

## 项目结构

```
.
├── README.md        # 本文件
├── MUSIC.md         # 简谱标记规则 & 口琴谱规则
├── package.json     # npm 启动脚本
├── scripts/
│   └── start-server.mjs # 本地静态服务器
├── index.html       # 口琴练习系统（纯前端）
└── 我的祖国.txt     # 简谱示例文件
```

## 快速开始

使用 npm 启动本地预览服务器：

```bash
npm install
npm start
```

默认地址是 <http://127.0.0.1:8080>。打开页面后，点击「选择文件」加载任意 `.txt` 简谱文件。

如需指定端口：

```bash
npm start -- --port 3000
```

## 功能

- 简谱文件解析（支持 `#` 升降号、多八度标记、休止符 `0`）
- 12 格 / 20 格两种口琴孔位模式切换
- 吹气音符（1,3,5）绿色显示，吸气音符（2,4,6,7）红色显示
- 多栏布局（1-10 栏可调）
- 歌词展示（`//` 注释内容）
- 句块分隔显示
- 响应式适配
